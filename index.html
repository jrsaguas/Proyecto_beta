¿Qué es?

Un sistema que puede observar contexto, decidir, usar herramientas, ejecutar acciones, evaluar resultados y repetir el ciclo hacia un objetivo.

Arquitectura

Modelo + objetivo + estado + memoria + herramientas + runtime + evaluación + guardrails.

Seguridad

Prompt injection, abuso de herramientas, privilegios excesivos, exfiltración, memoria contaminada y falta de trazabilidad.

Open source

Frameworks como LangGraph, CrewAI, Agent Framework, Dify, LlamaIndex, Haystack, OpenHands y Browser Use.

El ciclo agentivo

Objetivo → Observar → Interpretar → Planear → Validar → Ejecutar → Evaluar → repetir o terminar.
