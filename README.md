# Proyecto_beta — Investigación sobre IA agentiva

Proyecto de investigación y divulgación sobre inteligencia artificial agentiva (Agentic AI): fundamentos, arquitectura, herramientas, frameworks, seguridad, costos y opciones gratuitas/open source.

## Contenido
- investigacion_ia_agentiva.md: investigación extensa y referencias.
- informe_ia_agentiva.docx: informe académico con conceptos clave.
- comparativa_ia_agentiva.xlsx: matriz comparativa de frameworks y plataformas.
- index.html: página web interactiva.
- server.py: servidor Python local y API JSON.
- build_documents.py: script para regenerar DOCX/XLSX.
- .github/workflows/pages.yml: publicación automática en GitHub Pages.

## Ejecutar localmente
Requiere Python 3.10+ para el servidor.

    py -3 server.py

Después abre http://localhost:8000

Para regenerar los documentos:
    py -3 build_documents.py

## Alcance de “gratuito”
“Gratis” no significa necesariamente que el modelo de inferencia sea gratuito. La matriz distingue software open source/self-hostable, cuotas gratuitas de proveedores y servicios comerciales. Los costos y límites pueden cambiar.
